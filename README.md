# 서리 동굴: 온도 탐험대

중1 정수와 유리수의 사칙계산으로 온도를 조절하는 8단계 경로 탐사입니다. 온도 도구·에너지·남은 행동을 관리하고, 보급소 우회와 냉기 보호를 선택해 눈꽃 보물을 가지고 탈출합니다. 초반 덧셈 반복은 후반에 실패하며 곱셈·나눗셈, 경로 보급, 진입 후 위험 판단을 결합합니다.

## 실행과 배포
게임 폴더에서 npm test, npm run build, npm start를 사용합니다. Vercel에 이 저장소를 Import하면 vercel.json의 정적 빌드가 적용됩니다. 실제 Vercel 배포 URL은 아직 확인되지 않았습니다. PDF·내부 추출 원문은 저장소나 빌드에 없습니다.

## 성취기준과 기록
교육부 고시 제2022-33호 [별책8], PDF39쪽(인쇄33쪽) 9수01-05 및 해설, 적용 시 고려 사항 PDF40쪽을 대조했습니다. 새 수로 만든 독립 과제로 덧셈·뺄셈·곱셈·나눗셈·계산 원리를 확인합니다. 분수와 소수는 정확한 정수 비율로 비교합니다. 첫 응답·오답·재시도·도움·학생 설명·교사 검토를 익명 기기 기록에 저장하며 JSON 내보내기와 인쇄를 지원합니다. 게임 별과 도구 선택 로그는 독립 학습 증거로 세지 않습니다. 공식 이수 판정이나 교사 신원 인증은 아닙니다.

게임을 다시 열면 마지막 탐사를 처음부터 시작하며, 완료 별과 탐사 행동 기록은 보존합니다. 되돌리기는 현재 탐사 내에서만 가능합니다. 여러 학습자가 공유하는 기기에서는 학습 확인 기록을 내보낸 뒤 새 학습자를 시작하세요.

## 그래픽과 서체
내장 image_gen으로 동굴 배경, 북극여우 탐험가, 온도 장치·보급 가방·냉기 정령·보물 아틀라스를 직접 생성했습니다. assets/prompts.json에 원문 프롬프트와 사용 역할을 기록했습니다. 수직선·경로·수식은 코드로 표시하며 Jua, Do Hyeon, Gowun Dodum과 원본 라이선스를 theme에 포함했습니다.

## 검증과 한계
자동 테스트는 모든 스테이지의 승리 경로, 독립 수학 계산, 초기 전략의 실패 반례, 시간·자원 차이와 평가 기록을 확인합니다. 실제 브라우저와 390px 검증은 evidence/browser-review.json에 기록합니다. 실제 학생의 재미·학습 효과를 검증한 것은 아닙니다. 마법 온도 장치는 게임 규칙이며 실제 물리 장치의 모델이 아닙니다.
